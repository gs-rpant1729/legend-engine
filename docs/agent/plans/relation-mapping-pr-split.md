## Construction method

For each PR branch, built off the previous PR's branch:
- Whole-file adds/deletes: `git checkout <source-commit> -- <path>` / `git rm`.
- Entangled files: hand-construct the intermediate version by starting from the previous branch's copy and applying only that PR's classified hunks (function-level, using the manifest above as the map).
- After each PR's construction: diff its file list against the manifest to confirm nothing was missed, and confirm no stray hunks from later PRs leaked in.
- After PR5: `git diff pr5-tip relation-mapping-enhancements` must be empty — the golden invariant.
- No local build/compile (unavailable on this machine) — correctness rests on the golden invariant plus per-PR CI once pushed.
